# Flores amarillas animadas

Página web animada lista para Visual Studio Code, GitHub y Render.

## Abrir en Visual Studio Code

1. Descomprimí el archivo ZIP.
2. Abrí Visual Studio Code.
3. Entrá en **Archivo > Abrir carpeta**.
4. Elegí la carpeta `flores-amarillas`.
5. Abrí `index.html` con la extensión **Live Server**.

## Archivos

- `index.html`: contenido de la página.
- `style.css`: diseño, flores y animaciones.
- `script.js`: estrellas, interacción y mensaje.
- `assets`: diez fotografías, la canción actualizada y el fondo del universo.
- `render.yaml`: configuración para publicar en Render.

La canción incluida se activa al presionar **Descubrí tu mensaje** o el botón **Música**.

## Publicar

Subí estos archivos a un repositorio de GitHub. En Render elegí **New > Static Site**, conectá el repositorio y usá `.` como Publish Directory. No necesita comando de compilación.
